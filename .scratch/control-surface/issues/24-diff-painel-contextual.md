# 24: Usar Diff como Painel contextual

**What to build:** Permitir que a pessoa abra e organize múltiplos Painéis Diff, seguidores ou fixos, sem confundir mudanças entre Workspaces.

**Blocked by:** 23/Usar Files como primeiro Painel Dockview

**Status:** ready-for-agent

- [ ] Diff exibe mudanças Git do Workspace correto usando o serviço existente.
- [ ] Instâncias seguidoras acompanham a seleção segura e instâncias fixas mantêm seu contexto.
- [ ] Uma mudança insegura auto-fixa o Painel e informa a pessoa.
- [ ] Move, hide/reopen, floating e popout preservam o estado relevante.
- [ ] O fluxo passa em smoke no Web e no AppImage.
